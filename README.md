# reference-manager

Reference-management packages for Effect, published under the `@thomasfosterau` scope.

| Package | Purpose |
| --- | --- |
| [`@thomasfosterau/biblio`](packages/biblio/README.md) | CSL-JSON records as Effect Schema, checksummed ISBN / DOI / ISSN / ORCID identifiers, BibTeX / RIS / CSV / CSL-JSON parsing, same-work dedup, APA / Vancouver rendering (`.`), and Crossref / OpenAlex / OpenLibrary lookup over `HttpClient` (`./sources`). Peer: `effect`. |

**Disclaimer:** this repository and its packages have been created using Claude Code. The API is in flux; expect churn and breaking changes.
